# Page patterns by kind of part

What a part page usually calculates and warns about, by kind of part. Use the nearest existing page as the model (`npm run parts-index` lists them by category), and see [conventions.md](conventions.md) for the rules every page follows.

| Kind of part | Calculated or looked-up tables | Things to watch usually carries |
| --- | --- | --- |
| **LDO** | Headroom against load, dissipation and junction temperature in a worked example. Adjustable LDOs: check of the datasheet's resistor table against its own equation, divider current, worst-case output error, lowest input by load, start-up time against the noise-reduction capacitor, heat by VI and VO | PSRR needs the large capacitors, ripple rejection near dropout, enable must follow the input, no reverse-current limit |
| **Buck** | Feedback-resistor E-series table with divider current, inductor ripple and peak against the current limit, light-load loss from efficiency plots (by eye), a worked example with a loss budget (asynchronous bucks add diode loss) | |
| **Boost / buck-boost** | Load allowed by the current limit across input voltage, register-word tables for I²C parts, bypass-mode heating, worked examples at low and high input, the inductor/capacitor matrix as printed, boost-mode inductor current against the average limit | |
| **Motor driver** | Truth table, chopping current against VREF and the sense resistor, conduction loss and junction temperature | Brake-between-pulses options drive the motor while the PWM input is low; coast options put both inputs low in each off phase |
| **LED driver / dimming interface** | Sense resistor against LED current, duty against string voltage, current at the switch limit; clamp-voltage divider tables, duty limits, frequency against the FSET capacitor, recalculation of the datasheet's example | |
| **Amplifier, shunt, comparator** | Error budget by input level (offset against gain error), full-scale sense voltage by shunt and gain, comparator threshold and trip tables, highest shunt voltage against the rail, common-mode offset from the CMRR, total error against sense voltage (RSS), input-filter error, reference-connection table | Which pin numbering goes with which package |
| **Class-D amplifier** | Power by supply and load, volume-code formulas, register-map summary, start-up write list, protection table, output-filter corner and Q, heat and supply budget | Starts in shutdown with volume muted; reset RC holds reset unless the host drives it |
| **I²C power monitor** | Register map, address-pin table, calibration value and current LSB by shunt, offset as a current, error budget, update interval against averaging, alert-limit codes | Logic thresholds relative to the supply |
| **Multi-rail PMIC** | Regulator overview, sequence, output-voltage code formulas, register map, protection summary, inductor and capacitor checks, a worked I²C write | Settings reset after a fault shutdown, enable pins that are outputs, I²C dead until reset is released, latched protection, strap pins settled before the supply |
| **ADC** | Configuration words and frames, input-filter error, throughput against SCLK, input range against reference, application error budget | |
| **Voltage reference** | Error budget in ppm, volts and LSBs, self-heating with θJA, shunt series-resistor table, a worked example feeding an ADC reference | |
| **Flyback / AC-DC** | Thresholds from resistor dividers, turns and clamp calculations, heat budget; for off-line switcher families: output power by package and input, current limit and RDS(ON) per device, line-sense thresholds against the sense resistor with tolerance spread, input capacitance per watt, loss from measured efficiency | Table conditions, the V-pin resistor effect on the overvoltage point, bias-winding latch, no-load tuning, mirrored-footprint traps |
| **Load switch / power mux / PD controller** | Register, address and limit tables, calculated loss and discharge tables | |
| **Wireless MCU module** | Spec groups for supply and logic levels, current by mode, wireless, boot and reset timing, memory and peripherals, ratings; body: what is on the module, part numbers and variants, pins and strapping, powering and starting it, calculated enable delay and supply sizing, antenna placement | Module against bare chip, the 65 °C ambient limit of some variants |
| **MCU carrier-board recipe** | Design requirements, regulator headroom at a transmit burst, regulator heat and swap requirements, pin-assignment table, enable delay, programming-header pin order, USB pair impedance, I²C rise time, LED currents, current budget, stackup, routing, bring-up checklist | |
| **Energy-metering IC** | Spec groups by supply, ADC and timing; ADC step size checked against the datasheet's formula, divider loading against the ADC input impedance, CT channel (burden, input range, current range), battery backup time, crystal fit, a worked front end; the measurement path, memory, reset and power-up, battery options and the full pin table are `###` subsections of How it works | No supply headroom against the absolute maximum, floating-pin leakage in battery modes, calibration needs, sleep current against the front page, hardware-only datasheets (register map and code in manuals) |
| **Fuel gauge** | Supply and current by mode, measurement, digital pins, I²C timing and pull-up tables, register units and defaults decoded, sense voltage and resistor loss, supply drain over time, thermistor bias; body: pins (a ball table and a small grid of ours when the datasheet's figure has no names), power modes, interface and register map, both application circuits | What survives a power cycle, the headline current needing a setting, pin-leakage limits against pull-ups, which package numbers the pins how |

For front-sheet-only datasheets (a public two-page sheet): use the features, applications and the one figure; label product-page rows "(product page)"; add a spec group of what the public datasheet doesn't give; and say in How it works what the page can't tell.
